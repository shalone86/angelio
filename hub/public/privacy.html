Privacy Policy

angelio.org

No accounts, no ads, no tracking

Angelio doesn't ask children for names, emails or accounts, shows no ads, and uses no tracking or analytics cookies.

Progress stays on your device

Stars, stickers and settings are saved in your browser's storage on your device. We can't see them.

The read-aloud voice

When the natural voice reads a sentence, the text of that sentence (like “How many ones?”) is sent to Cloudflare to be spoken. It contains no personal information.

Speech checks (voice recordings)

When your child taps the microphone, a short recording is sent to our server at Cloudflare to be turned into text, so the game can check the word. The recording is used only for that, it is not stored, and no person listens to it. It's discarded as soon as the text is made. We keep a count of speech checks per family code (and, without a code, per day for each network, using a scrambled one-way fingerprint, not the address itself) to apply the limits.

Buying a family code

Payment is handled by Stripe; we never see card numbers. We receive the buyer's email and name to connect the code to the purchase and to help if a code is lost.

Parents

Questions, or want a family code removed? Email support@angelio.org.
