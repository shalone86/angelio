# Maps, Grids & Geometry

Free interactive **Maps, Grids & Geometry** learning app for **Grades K–5**, part of [Angelio](https://angelio.org/math/).

- **18 levels across 4 grade bands:**
  - **Grades K–1:** Position words, grid step paths, sides & corners, first symmetry, and parish/town landmark maps.
  - **2nd Grade:** Grid addresses (`A3`, `B4`), compass rose directions (`N/S/E/W`), map scale & closest place, polygons, and mirror grid reflections.
  - **3rd Grade:** Points/segments/rays/lines (parallel, perpendicular), angles with interactive `📐 Corner tester`, quadrilaterals, and lines of symmetry.
  - **Grades 4–5:** Reading and plotting Quadrant I `(x, y)` coordinates, reading protractors & missing angles, and 3D unit-cube volume (`L × W × H` + interactive layer builder).
- **Zero accounts, works offline, everything read aloud.**

```sh
npm test              # run all tests
npm run deploy -- maps # deploy Cloudflare Worker (at repo root)
```
